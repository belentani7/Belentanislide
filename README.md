# Belentanislide

App de presentaciones con IA.

## Qué es

Una aplicación que genera presentaciones con modelos de IA. Incluye un pack abierto de datos
de modelos para que el usuario elija con criterio en vez de a ciegas.

## Puesta en marcha

```bash
npm install
npm run dev
```

## Configuración

Requiere clave de Gemini. Copiar `.env.example` a `.env` y rellenar. La clave no se versiona.
